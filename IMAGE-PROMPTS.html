How to use
  • Generate each image and save it with exactly the filename shown (for example hero-water-softener-st-george-ut.png, or .jpg/.webp) in one folder.
  • Convert and wire them in with node scripts/prepare-images.mjs --src <folder> in the site project (WebP, max 1200 px wide, hero 1376 px, optional translucent logo stamp), then npm run import-content.
  • Export size: WebP under 1,200 px wide. The sizes below are the target after export. Generate larger if the tool allows, then downscale.
    • Tool tips
  • Midjourney: add --ar with the ratio shown under each prompt, --style raw, and --no text, letters, logos, people, person, hands, faces, watermark.
  • Tools with a negative-prompt field: text, letters, numbers, logos, watermark, brand names, people, person, hands, fingers, body parts, silhouette, reflection of a person, face, faces, extra fingers, deformed hands, cartoon, illustration, 3d render
  • Gemini, DALL-E, ChatGPT images: use the prompt as written. If text still appears on a surface, regenerate or add "no text of any kind on any surface".
    • Rules these prompts follow
  • No people at all. No faces, hands, gloved hands, figures or silhouettes: every photo shows equipment and rooms only, which also avoids implying real staff.
  • No text, numbers, logos or brand names. Equipment is deliberately generic and unbranded. Diagrams and charts are built in code.
  • Local but honest. Southern Utah homes, limestone, live oaks, slab floors and garage installs. No invented business claims, awards, vehicles or real addresses. Town pictures show typical housing only.
  • Brand-matched color. Navy and copper accents echo the site palette (#17496B, #C2562B).
  • Keep the set consistent. Generate everything in one session, reuse the same garage description and lighting.

    • Check each result for stray text or logos, extra fingers, plumbing that makes no sense (pipes to nowhere, a salt-free unit with a brine tank) and visible faces. Regenerate if any appear.
